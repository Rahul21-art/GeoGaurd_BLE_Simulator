How this simulator works

This website replaces the ESP32 + GPS trackers while hardware is not ready. Each student has an ID, GPS location, battery and SOS status, and the data format is the same one the real trackers send over BLE.

When real hardware is used, stop this simulator and clear its students. The student app and the dashboard need no changes.
