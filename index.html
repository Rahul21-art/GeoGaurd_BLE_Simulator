How this simulator works

This website acts as a temporary ESP32 tracker simulator. Multiple student trackers can be created and simulated.

Each student has a separate Student ID, GPS location, battery percentage and SOS status.

Later, the real ESP32 + GPS hardware will replace this simulator without changing the overall data format.
